# Pitch deck

The five-slide deck for the Cadence pitch: problem, solution, demo, privacy and security, and scaling.

- [slides.pdf](slides.pdf) is the deck to present or share, one 1920×1080 page per slide.
- [slides.html](slides.html) is the same deck as a web page. Open it in a browser, or print it to get the PDF again.
- [SPEAKER_NOTES.md](SPEAKER_NOTES.md) has what each person says on each slide.
- [images/](images) holds the app screenshots the slides use.

The shot list for the three-minute video is in [DEMO_VIDEO.md](../DEMO_VIDEO.md).
